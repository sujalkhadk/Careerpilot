CareerPilot – AI Career and Resume Assistant

CareerPilot is a web-based AI-powered career and resume assistant designed to help students analyze their career options, improve their resumes, and prepare for job opportunities.

Features

- Career Analysis: Matches student skills with suitable career paths.
- ATS Resume Scoring: Evaluates resumes and provides improvement suggestions.
- Resume Analysis: Extracts and analyzes information from uploaded PDF resumes.
- AI Interview Questions: Generates interview questions based on career goals and skills.
- Job Recommendations: Finds relevant job opportunities in India.
- Resume Builder: Generates professional resume drafts.
- Multiple Resume Layouts: Offers three selectable resume designs, including photo and standard layout options.

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- MySQL
- Gemini API
- PyMuPDF
- Python-JobSpy

Project Structure

- "app.py" – Main Flask application
- "job_scraper.py" – Job scraping functionality
- "templates/" – HTML pages
- "static/" – Static assets, if present
- "requirements.txt" – Python dependencies

How to Run

1. Clone this repository.

2. Install the required dependencies:
   
   "pip install -r requirements.txt"

3. Configure your MySQL database.

4. Set your Gemini API key as an environment variable if using AI interview generation.

5. Run the application:
   
   "python app.py"

6. Open "http://127.0.0.1:5000" in your browser.

Project Purpose

CareerPilot was developed as a B.Sc. Computer Science mini project to help students understand their career opportunities and improve their job readiness.
